# HU-IDEAM-SNIF-REST-021

> **Identificador Historia de Usuario:** hu-ideam-snif-rest-021\
> **Nombre Historia de Usuario:** Control de funcionalidades del visor por rol

> **Sistema de información:** Sistema Nacional de Información Forestal\
> **Módulo / subsistema:** Módulo de restauración\
> **Validador temático(s):** Raymond Alexander Jiménez Arteaga

## DESCRIPCIÓN HISTORIA DE USUARIO

> **Como:** administrador del sistema.\
> **Quiero:** que el sistema habilite o restrinja funcionalidades del visor según el rol.\
> **Para:** garantizar segregación funcional, manteniendo el visor como herramienta de consulta para todos los perfiles.

## CRITERIOS DE ACEPTACIÓN

1. **Control por rol**  
   1.1 El sistema debe habilitar o restringir funcionalidades del visor según el rol.

2. **Segregación funcional**  
   2.1 Debe garantizarse segregación funcional entre roles.

3. **Visor de consulta**  
   3.1 El visor se mantiene como herramienta de consulta para todos los perfiles.

## ROLES

- **Administrador IDEAM:** Administra el control de funcionalidades por rol.

- **Registrador:** Accede a funcionalidades según su perfil.

- **Usuario Consulta / Invitado:** Accede a funcionalidades de consulta.

## RESTRICCIONES Y LÍMITES

- Las restricciones se aplican según el rol asignado.
- El visor es de consulta para todos los perfiles.
- La segregación funcional es obligatoria.
