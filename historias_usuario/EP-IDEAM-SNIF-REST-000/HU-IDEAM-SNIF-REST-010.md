# HU-IDEAM-SNIF-REST-010

> **Identificador Historia de Usuario:** hu-ideam-snif-rest-010\
> **Nombre Historia de Usuario:** Consultas geográficas

> **Sistema de información:** Sistema Nacional de Información Forestal\
> **Módulo / subsistema:** Módulo de restauración\
> **Validador temático(s):** Raymond Alexander Jiménez Arteaga

## DESCRIPCIÓN HISTORIA DE USUARIO

> **Como:** usuario del SNIF.\
> **Quiero:** acceder a consultas geográficas sobre información validada.\
> **Para:** obtener información específica del territorio.

## CRITERIOS DE ACEPTACIÓN

1. **Tipos de consulta**  
   1.1 El sistema debe permitir los siguientes tipos de consulta:  
   - Consulta atributiva.  
   - Consulta espacial.  
   - Consulta por coordenadas.  
   - Consulta por cargue de geometría.  
   - Estadísticas generales.

## ROLES

- **Todos los perfiles:** Pueden realizar consultas.

## RESTRICCIONES Y LÍMITES

- Las consultas se realizan sobre información validada.
- No se permite modificación de datos desde las consultas.
